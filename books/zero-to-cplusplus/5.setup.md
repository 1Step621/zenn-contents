第2章から第4章にわたって長いこと前提知識を解説してきましたが、ようやく環境構築に入ります。

> 環境構築
> プログラムを書いて動かすために必要なソフトウェアをインストールすること

C++を書くために必要なソフトウェアは大きく分けて2種です。
- コンパイラツールチェーン
  - 人間に読みやすい形式であるC++を、コンピューターへの指示である実行ファイルに変換するためのツール集。
- エディタ
  - ソースコードを入力補完つきで快適に編集するためのツール。

それぞれいろいろな選択肢があるのですが、ここではコンパイラツールチェーンとしてLLVM-MinGWを、エディタとしてVisual Studio Code(よくVSCodeと略されます)を利用するセットアップを利用します。

## やってみる

環境構築の際に便利なコマンドとして、`winget`があります。`winget`はターミナルから手軽にソフトウェアをインストールするためのコマンドです。
ソフトウェアの名前をいれるだけで、収録されているソフトウェア集から検索してダウンロードできます。

```powershell:構文
winget install ソフトウェアの名前
```

これを使って環境を構築します。

以下のコマンドを実行してください。
```powershell
winget install MartinStorsjo.LLVM-MinGW.UCRT
winget install Microsoft.VisualStudioCode
```

wingetの初回実行時はライセンス契約画面が出るので、読んで同意してください。
![ライセンス契約画面](/images/books/zero-to-cplusplus/winget-license-agreement.png)
`Y`を入力してEnterすると同意したことになります。

これによって、`clang++`コマンドと`code`コマンドが利用可能になります。

`clang++`コマンドはコンパイラツールチェーンのうち、コンパイラ^[コンパイルだけでなくプリプロセス、アセンブル、リンクも行うため、コンパイラドライバーと呼ぶのがより正確ですが、単にコンパイラと呼ばれることも多いので、この表現としています。]と呼ばれる、C++を実行ファイルに変換するためのツールです。これについては後述します。

`code`コマンドがエディタです。試しに起動してみましょう。
一度ターミナルを開き直し、
```powershell
code
```
と入力してみてください。
