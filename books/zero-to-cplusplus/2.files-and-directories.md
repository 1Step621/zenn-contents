第1章でも説明しましたが、プログラミングを始めるには、まず環境構築が必要です。

> 環境構築
> プログラムを書いて動かすために必要なソフトウェアをインストールすること

では環境構築を始めましょう！と言いたいところなのですが、前提知識として**ファイル**と**フォルダ**について解説します。

## ファイル

ファイルは紙のようなものです。例えば、コンピューターにあなたの日記を保存しておきたいとします。

まず「メモ帳」アプリを起動して、日記の内容を考えます。Windowsキーを押して、検索窓に「メモ帳」と入力すると起動できます。

![メモ帳](/images/books/zero-to-cplusplus/memopad.png)

![日記](/images/books/zero-to-cplusplus/diary.png)
_メモ帳_

考え終えたら、これを紙に書き込んで名前をつけてとっておきたいと思うわけです。この紙がファイルです。
メモ帳アプリでCtrlキーを押しっぱなしにしたままSキーを押す^[以降、このような操作をCtrl+Sと表現します]か、左上の「ファイル」メニューから「名前をつけて保存」を選択するとファイル作成画面を開くことができます。

![ファイル作成画面](/images/books/zero-to-cplusplus/file-save.png)
_ファイル作成画面_

今回は「2026-08-01.txt」という名前を付けることにします。

ちなみに、この「.txt」は **拡張子**と言って、ファイル名の最後にくっつける取り決めになっています。拡張子はファイルの内容をざっくり識別するために使われ、.txtの場合は装飾や付加情報などを含まない純粋な文字列が書かれたファイルであることを表します。

できたら、エクスプローラーを開いてドキュメントと書かれている場所をクリックしてください。

![エクスプローラー](/images/books/zero-to-cplusplus/explorer.png)
_エクスプローラー_

![ドキュメント](/images/books/zero-to-cplusplus/documents.png)
_ドキュメント_

するとさきほど作成したファイルが置いてあると思います。

![さきほど作成したファイル](/images/books/zero-to-cplusplus/file.png)
_ファイル_

これをダブルクリックして開くと、メモ帳で再度ファイルを見ることができるというわけです。

ところで、ファイル名の.txtが省略表示になってしまっています。これはWindowsがデフォルトでファイルの拡張子を表示しない設定になっているためです。
「表示」>「表示」>「ファイル名拡張子」から表示できるので、有効にしておくことをおすすめします。
![拡張子の表示](/images/books/zero-to-cplusplus/show-extension.png)

## フォルダ

さて、日記が増えてくると、「2026年の日記」を1つにまとめておきたいなという気持ちになってきます。ここで使われるのがフォルダ(ディレクトリとも呼ばれる)です。ファイルが紙なら、フォルダは箱のようなものです。

フォルダを作成するには、「エクスプローラー」アプリを起動してなにもない場所を右クリック(トラックパッドの場合は二本指でタップ)し、「新規作成」>「フォルダ」をクリックします。名前を入力できる状態になるので、「2026」という名前にしてみましょう。間違えて違う名前で確定してしまった場合は、当該フォルダを右クリックして「名前の変更」を選択するとやり直せます。

![新規フォルダの作成](/images/books/zero-to-cplusplus/create-new-folder.png)

![新規フォルダ](/images/books/zero-to-cplusplus/new-folder.png)

できたフォルダの上に2026-08-01.txtをドラッグアンドドロップすると、ファイルがフォルダに入ります。

> ドラッグアンドドロップ(D&D)
> ファイルをクリックしたまま離さずに移動(ドラッグ)したあと、特定の場所で離す(ドロップ)こと。

今、2026フォルダをダブルクリックして中身を見ると2026-08-01.txtが入っていることが確認できます。

現在の構造はこんな感じになっています。

```
2026
└── 2026-08-01.txt
```

もしかしたら、「2026年の日記」で1つにまとめる以外にも「8月の日記」で1つにまとめたくなるかもしれません。

その場合は、フォルダの中にフォルダを作ることもできます。手順はさきほどと全く同じです。

結果的に、このような構造にすることができます。

```
2026
└── 08
    └── 2026-08-01.txt
```

## コンピューターのファイル構造

メモ帳でファイルを作ったときに、「ドキュメント」という場所に置かれていたのを覚えているでしょうか。

この「ドキュメント」も実はフォルダなのです。さきほどの書き方で書くとこのようになります。

```
Documents
└── 2026
    └── 08
        └── 2026-08-01.txt
```

更に言うと、「Documents」は「(あなたのWindowsユーザー名)」フォルダの中にあります。

```
(あなたのWindowsユーザー名)
├── Documents
│    └── 2026
│        └── 08
│            └── 2026-08-01.txt
├── Pictures
├── Videos
├── Downloads
...
```

「(あなたのWindowsユーザー名)」は「Users」フォルダの中にあります。

```
Users
├── (あなたのWindowsユーザー名)
│    ├── Documents
│    │    └── 2026
│    │        └── 08
│    │            └── 2026-08-01.txt
│    ├── Pictures
│    ├── Videos
│    ├── Downloads
│    ...
├── (他のWindowsユーザー名)
```

もう一個上に行くと、「C:」というへんてこな名前のフォルダに行き当たります。これ以上上のフォルダはありません。ここをルート(root: "根っこ"という意味)フォルダといいます。

コンピューター内のすべてのファイルは「C:」フォルダの中にあります。^[複数のドライブがある場合を除く。]

## パス

さて、コンピューターの中の特定のファイルやフォルダを読み出したいときなどに、「そのファイルやフォルダの場所」を表す表現があると便利です。単にファイル名、フォルダ名を書くだけだと

```
├── a
│   └── hoge.txt
└── b
    └── hoge.txt
```

というように、同じ名前のものが複数ある場合、どちらを指しているのかが区別できません。

ここで用いられるのがパス(path: "道筋"という意味)です。

パスでは、フォルダのたどり方を`\`で区切って書きます。
例えば、「『C:』の中の『Users』の中の『onestep』の中の『Documents』の中の『2026』の中の『08』の中の『2026-08-01.txt』」は`C:\Users\onestep\Documents\2026\08\2026-08-01.txt`のように表現されます。

このように「C:」を起点とするパスを「絶対パス」と言います。

一方で、たどり始めるフォルダは必ずしも「C:」でなくても構いません。`C:\Users\onestep`からたどり始めているパスであるという前提を共有していれば、`Documents\2026\08\2026-08-01.txt`だけで十分ですね。このように、「C:」でないフォルダを起点とするパスを「相対パス」と言います。

では、`C:\Users\onestep`を起点とする相対パスで、`C:\Users\twostep\my-folder`を表現したい場合はどうしたらいいのでしょうか。相対パスでは、`..`という表現を使うことで、1つ上のフォルダを指すことができます。これを使うと、`..\twostep\my-folder`という表現で`C:\Users\twostep\my-folder`を表現できます。「1個上のフォルダの中の『twostep』の中の『my-folder』」という具合ですね。

さらに、`C:\Users\onestep`を起点として`C:\Users\onestep`を表現する(つまり、起点そのものを表現する)には`.`を使います。そんなのいつ使うんだと思うかもしれませんが、たまに使います。

ちなみに、Windowsではパスの大文字小文字を区別しません。`C:\Users\onestep`と`c:\users\onestep`は同じフォルダを指します。

## 演習問題

- `C:\Users\onestep`を起点とする相対パスで、`C:\Users\onestep\Downloads\hoge.txt`を表現するにはどうしたらいいでしょう？
- `C:\Users\onestep`を起点とする相対パスで、`C:\Users\onestep\Pictures`を表現するにはどうしたらいいでしょう？
- `C:\Users\onestep\Documents`を起点とする相対パスで、`C:\Users\twostep\Documents`を表現するにはどうしたらいいでしょう？
- `C:\Users`を起点とする相対パスで`onestep\Documents`と表現される場所の絶対パスは何でしょう？

:::details 解答

- `Downloads\hoge.txt`
- `Pictures`
- `..\..\twostep\Documents`
- `C:\Users\onestep\Documents`
  :::
